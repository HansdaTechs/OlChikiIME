## 🚀 About

OlChikiME is a next-generation keyboard designed for the Santali community, enabling fast, accurate, and modern typing in the Ol Chiki script.

Unlike traditional keyboards, OlChikiME focuses on:

* Native Ol Chiki typing
* Gaming-inspired modern UI
* Developer-friendly layouts
* Fast performance
* Beautiful themes
* Future-ready language technology

The mission of OlChikiME is to make Santali digital communication easier, faster, and more accessible across Android devices.
